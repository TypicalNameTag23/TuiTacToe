# Prerequisites
- .net 10 SDK installed on your machine

# Running
```
git clone https://github.com/TypicalNameTag23/TuiTacToe.git
cd TuiTacToe
cd Scripts
dotnet run

# Run all the initial setup scripts

cd ../Client
dotnet run

# In separate terminal
cd Path/To/TuiTacToe/Server
dotnet run

ssh 127.0.0.1
```
